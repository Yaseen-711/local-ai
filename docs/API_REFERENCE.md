# REST API & SSE Streaming Reference

The Sovereign Industrial AI Workbench exposes an asynchronous, air-gapped REST API powered by FastAPI, alongside a Server-Sent Events (SSE) streaming bus for real-time task observability.

Base URL: `http://127.0.0.1:8000/api/v1` (or `http://localhost:8000/docs` for interactive Swagger UI).

---

## 1. Goal Lifecycle & Planning Endpoints (`/goals`)

### 1.1 Create & Plan a Goal
Submits a natural language engineering objective. The `DecisionEngine` evaluates intent and either generates a DAG execution plan or routes to a direct capability.

* **Method**: `POST /api/v1/goals`
* **Request Body**:
```json
{
  "title": "FV-201A Integrity & Compliance Audit",
  "description": "Review P&ID against equipment specs, calculate margin, and generate XLSX workbook.",
  "inputs": {
    "file_id": "file_8f29ac01_pid"
  },
  "parameters": {
    "max_steps": 10,
    "require_artifact": true
  }
}
```
* **Response** (`201 Created`):
```json
{
  "goal_id": "goal_7d821e90",
  "title": "FV-201A Integrity & Compliance Audit",
  "description": "Review P&ID against equipment specs...",
  "status": "planned",
  "active_plan_id": "plan_99a12c",
  "created_at": "2026-09-07T10:00:00Z",
  "context": {},
  "links": {
    "execute": "/api/v1/goals/goal_7d821e90/execute",
    "events": "/api/v1/goals/goal_7d821e90/events",
    "status": "/api/v1/goals/goal_7d821e90"
  }
}
```

### 1.2 Inspect Candidate Plan
Retrieves the candidate DAG plan generated by `LLMPlanner` before or after execution.

* **Method**: `GET /api/v1/goals/{goal_id}/plan`
* **Response** (`200 OK`):
```json
{
  "goal_id": "goal_7d821e90",
  "plan_id": "plan_99a12c",
  "strategy": "plan_required",
  "route": "complex_workflow",
  "is_valid": true,
  "validation_errors": [],
  "tasks": [
    {
      "task_id": "step_1",
      "capability_id": "vision.inspect",
      "title": "Detect tag FV-201A in P&ID",
      "status": "pending",
      "dependencies": [],
      "parameters": {"file_id": "file_8f29ac01_pid", "query": "Find tag FV-201A"}
    },
    {
      "task_id": "step_2",
      "capability_id": "retrieval.rag",
      "title": "Retrieve design specifications",
      "status": "pending",
      "dependencies": ["step_1"],
      "parameters": {"query": "What is the design pressure and material of FV-201A?"}
    },
    {
      "task_id": "step_3",
      "capability_id": "artifact.generate",
      "title": "Generate engineering workbook",
      "status": "pending",
      "dependencies": ["step_2"],
      "parameters": {"artifact_type": "xlsx", "title": "FV-201A Audit Workbook"}
    }
  ]
}
```

### 1.3 Execute a Goal
Launches asynchronous execution of the validated DAG plan via `InProcessPlanRunner`.

* **Method**: `POST /api/v1/goals/{goal_id}/execute`
* **Response** (`202 Accepted`):
```json
{
  "goal_id": "goal_7d821e90",
  "plan_id": "plan_99a12c",
  "status": "running",
  "events_url": "/api/v1/goals/goal_7d821e90/events"
}
```

### 1.4 Get Goal Status & Output Details
* **Method**: `GET /api/v1/goals/{goal_id}`
* **Response** (`200 OK`): Returns detailed status, task execution history, resulting artifacts, and error states.

### 1.5 Cancel Goal Execution
* **Method**: `POST /api/v1/goals/{goal_id}/cancel`
* **Response** (`200 OK`): Immediately signals the task runner to halt pending and in-flight tasks.

## 2. Server-Sent Events (SSE) Stream (`/goals/{goal_id}/events`)

The event bus streams execution facts in real-time. To prevent internal reasoning or prompt leakage, thinking tokens are automatically stripped from all stream payloads.

* **Method**: `GET /api/v1/goals/{goal_id}/events`
* **Protocol**: `text/event-stream`

### Stream Lifecycle Events

```text
event: stream.connected
data: {"goal_id": "goal_7d821e90"}

event: goal.started
id: 1
data: {"goal_id": "goal_7d821e90", "plan_id": "plan_99a12c", "timestamp": "2026-09-07T10:00:01Z"}

event: task.started
id: 2
data: {"goal_id": "goal_7d821e90", "task_id": "step_1", "capability_id": "vision.inspect"}

event: task.completed
id: 3
data: {"goal_id": "goal_7d821e90", "task_id": "step_1", "output": {"detected_tag": "FV-201A"}}

event: artifact.created
id: 4
data: {"artifact_id": "art_1982ab", "filename": "FV-201A_Audit.xlsx", "hash": "e3b0c442..."}

event: goal.completed
id: 5
data: {"goal_id": "goal_7d821e90", "status": "completed", "duration_ms": 3421.5}
```

## 3. Direct Capability Execution (`/direct`)

Bypasses the decision and planning engine for synchronous, direct capability invocation.

### 3.1 Direct Vision Inspection
* **Method**: `POST /api/v1/direct/vision`
* **Request**:
```json
{
  "file_path": "golden_test_pack/05_pid_direct_input.png",
  "query": "Identify valve tag FV-201A and its connected line size",
  "model_id": "qwen3.5-9b",
  "temperature": 0.1
}
```

### 3.2 Direct Document Parsing
* **Method**: `POST /api/v1/direct/document`
* **Request**:
```json
{
  "file_path": "golden_test_pack/04_direct_only_datasheet.pdf",
  "query": "What is the design pressure and asset tag in this document?",
  "do_ocr": true,
  "extract_tables": true
}
```

### 3.3 Direct Artifact Generation
* **Method**: `POST /api/v1/direct/artifact`
* **Request**:
```json
{
  "artifact_type": "xlsx",
  "title": "Equipment Inspection Summary",
  "filename": "inspection_summary.xlsx",
  "data": {
    "Inspection": [
      ["Tag", "Design Pressure (barg)", "Observed Condition"],
      ["FV-201A", 45.0, "0.12 mm corrosion - Routine Maintenance"]
    ]
  }
}
```

### 3.4 Direct Text Analysis
* **Method**: `POST /api/v1/direct/text-analysis`
* **Request**:
```json
{
  "text": "Routine inspection of FV-201A revealed minor wall thinning of 0.12 mm.",
  "depth": "detailed",
  "focus": "maintenance findings"
}
```

## 4. Sovereign RAG Endpoints (`/rag`)

Operates against the dedicated `local_ai_rag` PostgreSQL database.

### 4.1 Ingest Document
* **Method**: `POST /api/v1/rag/ingest`
* **Request**: `{"file_path": "golden_test_pack/01_equipment_spec.pdf"}`
* **Response** (`200 OK`):
```json
{
  "document_id": "doc_9128f",
  "file_name": "01_equipment_spec.pdf",
  "format": "pdf",
  "page_count": 2,
  "chunk_count": 6,
  "action": "created",
  "timings": {"parse_s": 0.21, "embed_s": 0.35, "index_s": 0.05}
}
```

### 4.2 Explicit Semantic Search (No LLM Synthesis)
* **Method**: `POST /api/v1/rag/search`
* **Request**:
```json
{
  "query": "What is the design pressure of FV-201A?",
  "top_k": 10,
  "top_n": 3
}
```
* **Response**: Returns ranked chunk candidates, cosine similarity scores, cross-encoder scores, section trails, and source page numbers.

### 4.3 Grounded Question Answering
* **Method**: `POST /api/v1/rag/qa`
* **Request**:
```json
{
  "query": "What is the design pressure and material of FV-201A?",
  "top_k": 10,
  "top_n": 3,
  "temperature": 0.1
}
```
* **Response**:
```json
{
  "query": "What is the design pressure and material of FV-201A?",
  "answer": "According to 01_equipment_spec.pdf (Page 1), FV-201A has a design pressure of 45.0 barg and is fabricated from 316L Stainless Steel.",
  "count": 3,
  "candidates": [...]
}
```

## 5. File Staging & Artifact Downloads

### 5.1 Upload Staged File
* **Method**: `POST /api/v1/files/upload`
* **Form-Data**: `file: <binary>`, `purpose: "vision"`
* **Response**: `{"file_id": "file_abc123", "filename": "pid.png", "size_bytes": 45123}`

### 5.2 Download Artifact
* **Method**: `GET /api/v1/artifacts/{artifact_id}/download`
* **Headers**: Includes `X-Artifact-Hash: <sha256>` for cryptographic verification.
* **Response**: Binary stream (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `application/pdf`, etc.).
